Database Projects

Facial Database

This project develops a facial database for a room access recognition system to eliminate issues like lost key cards, card sharing, and password inconvenience. By storing multi-angle facial images alongside user identity data, the system enhances recognition accuracy, ensures security, and enables efficient access log tracking.

Computer Vision Technology

HemoGrade AI

The HemoGrade AI project develops an artificial intelligence system to automatically analyze and classify red blood cell agglutination levels from Gel Card images. It is designed as a decision-support tool for medical technologists to help reduce human errors caused by visual fatigue and improve the consistency and accuracy of blood test readings.

Disaster Notification

Developed a robust disaster notification system by orchestrating automated batch data ingestion via Apache Airflow, transforming raw event data into clean models using dbt, and streamlining real-time alerting workflows through Discord to enhance incident awareness.
